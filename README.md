# Django Project: Book Management System

Этот проект демонстрирует создание модели данных, подключение её к админке и заполнение базы данных с помощью команды Django.

## Описание

Проект представляет собой систему управления книгами, где можно хранить информацию о книгах: название, автор, дата публикации и ISBN.

### Модели:
- **Book**: Модель для хранения информации о книгах.

### Основные действия:
1. Создание модели данных и миграции.
2. Создание суперпользователя и настройка админки.
3. Подключение модели в админку.
4. Создание команды Django для заполнения базы данных тестовыми данными.
5. Проверка данных через административную панель.
6. Пример использования `.gitignore` для исключения базы данных из репозитория.
